# Recipe Finder

## Identitas
- Nama: [isi nama]
- Kelas: [isi kelas]

## Fitur
- Mengambil 50 resep dari DummyJSON Recipes API.
- Mencari resep berdasarkan nama.
- Memfilter resep berdasarkan cuisine dan tingkat kesulitan.
- Membuka detail resep, bahan, dan langkah memasak.
- Menambah atau menghapus resep favorit.
- Menyimpan favorit di LocalStorage agar tetap ada setelah halaman dimuat ulang.
- Mendukung tampilan desktop dan mobile.

## Sumber API
- https://dummyjson.com/recipes

## Menjalankan Project
Buka `index.html` dengan browser atau gunakan ekstensi Live Server di VS Code.

## Kendala yang Ditemukan
API secara default mengirim sebagian data saja. Project ini meminta `limit=50` agar semua resep tersedia, lalu mengambil data JSON sebelum membuat tampilan kartu.
